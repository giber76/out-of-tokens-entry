## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` — 1 to 140 UTF-8 characters, nothing else. The blind judge compares lines two at a time and keeps the funnier one.
